# StackStorage

Minecraft Forge mod for 1.20.1 (Forge 47.4.10).

## Development setup

```
./gradlew genEclipseRuns   # or genIntellijRuns / genVSCodeRuns
./gradlew build
./gradlew runClient
```

Mod id: `stackstorage`
Base package: `com.facusora.stackstorage`

See `README.txt` for the original Forge MDK build instructions.
